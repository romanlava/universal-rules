# Universal Design & UX Rules

Централизованная база правил проектирования UX/UI для AI-ассистентов (Claude Code и др.).
Одна точка правды — подключается к любому проекту (CRM, SaaS, лендинги, мобильные приложения).

## Философия

**Максимальная универсальность и высокоуровневость.** Правила описывают законы и принципы
(когнитивная психология, гештальт, поведенческая экономика, доступность), а не пиксели
конкретного проекта. Всё проектно-специфичное живёт в CLAUDE.md самого проекта.

Правила написаны на английском — так плотнее и однозначнее для LLM.
Документация для человека (этот файл, интеграция) — на русском.

## Структура

```
INDEX.md                  ← компактный индекс: 1 строка на правило (грузится в контекст всегда)
rules/
  00_META_FRAMEWORK.md    ← формат и принципы базы правил
  _TEMPLATE.md            ← шаблон нового правила
  cognition/              ← когнитивная нагрузка, память, выбор
  behavior/               ← поведенческая экономика (потери, градиент цели, Парето…)
  gestalt/                ← законы восприятия (сходство, завершение, изоляция…)
  interaction/            ← паттерны взаимодействия (ошибки, статус, выходы, ускорители)
  robustness/             ← отказоустойчивость (Постел, Доэрти, Теслер)
  data/                   ← плотность данных, data-ink
  a11y/                   ← WCAG 2.2, COGA, инклюзивность
  content/                ← язык, микрокопирайтинг, voice & tone
skills/ux-architect/      ← упаковка как Claude Code skill
docs/INTEGRATION.md       ← как подключить к проекту (submodule / import / plugin)
docs/research/            ← исходные исследования и gap-анализы
```

## Ключевая механика: двухуровневая загрузка

Чтобы не раздувать контекст, в каждый проект всегда загружается только `INDEX.md`
(~30 строк). Полный текст правила ИИ открывает сам, когда триггер из индекса совпадает
с текущей задачей. Никогда не вставляйте всю базу правил в системный промпт целиком.

## Как подключить к проекту

Кратко (подробно — в [docs/INTEGRATION.md](docs/INTEGRATION.md)):

1. **Git submodule** (рекомендуется): версионируемая связка, работает в CI.
2. **Абсолютный @import** из CLAUDE.md проекта: ноль настройки, мгновенные обновления,
   но только для одной машины.
3. **Claude Code plugin**: установка через marketplace, автоподхват skill.

## Как обновлять

Правки делаются только здесь → commit → в проектах `git submodule update --remote`
(при подключении через submodule) или вообще ничего (при абсолютном import).

* ID правил неизменны; устаревшее правило получает `status: deprecated`, а не удаляется.
* Версионирование: SemVer в [CHANGELOG.md](CHANGELOG.md). Major — изменение формата/структуры,
  minor — новые правила, patch — правки текста.
